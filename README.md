
Este proyecto tiene como objetivo desarrollar un modelo de regresión lineal utilizando el conjunto de datos California housing, con el propósito de analizar la relación entre las características socioeconómicas de distintas zonas de California y el valor medio de sus viviendas.

El proyecto busca aplicar técnicas de análisis y modelado estadístico para comprender cómo diferentes variables pueden utilizarse para explicar y predecir los precios de las viviendas.

El análisis se divide en las siguientes etapas:

1. Análisis de exploración (EDA): exploración del conjunto de datos, análisis de variables y distribución de los valores.
2. Visual:  visualización de relaciones entre variables y análisis de correlaciones.
3. Regresión lineal simple: construcción de un primer modelo utilizando el ingreso medio (`MedInc`) como variable predictora.
4. Evaluación del modelo: evaluación del desempeño mediante métricas como MAE, MSE, RMSE y R².
5. Regresión lineal multiple: ampliación del modelo incorporando múltiples variables predictoras para analizar su contribución a la predicción del valor de las viviendas.
